About

Why this repo matters

This repository is meant to help students understand ethical hacking in a structured and practical way. Instead of jumping randomly between commands and tools, the roadmap moves from basics to real-world skill-building. It combines theory, tools, hardware, and labs so students can learn carefully and responsibly.

Hardware

Real hardware references students should understand

Raspberry Pi

A small single-board computer used for local labs, IoT testing, internal servers, and experiments. It is ideal for students to host vulnerable services in a safe isolated lab.

Flipper Zero

A multi-tool device for RFID, NFC, IR, and hardware experiments. Useful for learning hardware interfaces, but only in lab contexts and on devices you own.

RTL-SDR / HackRF

Software defined radio tools help students learn signal processing, wireless analysis, and passive monitoring in a controlled environment.

Proxmark3 / RFID Tools

Advanced RFID and NFC research hardware used for studying tags and card communications in authorized lab setups.

YubiKey / Hardware Tokens

Hardware-based authentication helps students understand MFA, strong security principles, and why cryptographic factors matter in real systems.

USB Rubber Ducky / WiFi Pineapple

These devices demonstrate how hardware can be used in testing and security research. They are valuable learning tools only in controlled lab environments.

Tools

Core tools students use regularly

nmap

Network scanning and service discovery.

nmap -sC -sV -p- 10.0.2.15

Wireshark

Packet capture and protocol study.

tcpdump -i eth0 -w capture.pcap

Burp Suite

Proxy tool for testing web apps and APIs.

sqlmap

Automated SQL injection testing.

sqlmap -u "http://10.0.2.15/vuln.php?id=1" --batch

Metasploit

Exploit framework for labs and learning.

LinPEAS / WinPEAS

Privilege escalation enumeration.

BloodHound

Active Directory relationship mapping.

Hashcat / John

Password hash analysis and cracking in labs.

Labs

How students practice

Lab 1 — Linux & Networking

Set up a local lab, understand IP addresses, routes, ports, scanning, packet capture, and safe environment isolation.

Lab 2 — Web Security

Use Burp Suite and OWASP testing flow to read requests, inspect responses, and analyze common vulnerabilities.

Lab 3 — Exploitation

Learn how exploits work, understand public exploit flow, and connect it with the concept of risk, mitigation, and patching.

Lab 4 — Privilege Escalation

Run enumeration tools, look for sudo misconfigurations, SUID binaries, and common escalation paths.

Lab 5 — Hardware / SDR

Practice with Raspberry Pi, SDR, and Flipper Zero in a controlled local environment. Learn about signals, radio, and embedded interfaces.

Lab 6 — Reporting

Write clear evidence-based findings with summary, reproduction steps, impact, and remediation guidance.

Legal

Use it safely and responsibly

  1. Only test systems you own or have explicit written permission to assess.
  2. Keep your lab isolated from home, office, or production networks.
  3. Never transmit on regulated radio bands without authorization.
  4. Document everything and learn from evidence, not random exploitation.

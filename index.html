Ethical Hacking Roadmap

Beginner → Pro | Learning repository | Education purpose only

⚠️ Legal: Use only on your own lab machines, CTF platforms (TryHackMe, HackTheBox), or authorized bug bounty scope. Unauthorized testing is illegal (IT Act 2000, Sections 43/66).

Level 1 — Beginner (0-3 months)

  • Networking: TCP/IP, OSI model, ports & protocols
  • Kali Linux in VirtualBox, terminal mastery, Bash basics
  • Lab: Metasploitable 2, DVWA, OWASP Juice Shop
  • Wireshark traffic analysis
  • Practice: TryHackMe Pre-Security + Complete Beginner paths

Level 2 — Intermediate (3-9 months)

  • Nmap deep scanning, recon tools, Google dorking
  • OWASP Top 10: SQLi, XSS, IDOR, SSRF, file upload and more
  • Burp Suite: Proxy, Repeater, Intruder
  • Password attack concepts, Metasploit, Python scripting
  • Practice: THM Jr Penetration Tester path, HTB easy boxes

Level 3 — Pro (9+ months)

  • Privilege Escalation: Linux + Windows
  • Active Directory attacks, post-exploitation concepts
  • Mobile & API security basics
  • Professional report writing (CVSS, remediation)
  • Certifications: eJPT → Security+ → CEH → OSCP
  • Bug bounty: HackerOne, Bugcrowd (in-scope only)

Golden Rules

  • 1. Hack only: your lab, CTF platforms, or written-permission scope
  • 2. Writeup for every machine → commit to this repo
  • 3. Machines over videos — learn by doing
  • 4. Break-and-fix: patch what you exploited
  • 5. Understand WHY it worked, not just the flag

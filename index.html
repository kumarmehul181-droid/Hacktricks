About

Built for consistent learning, not random tool hunting.

This repo helps students move from beginner fundamentals to professional-level security work without feeling lost. Each phase teaches a concept, a set of tools, and a way to practice safely. It is meant to support ethical hacking education with legal lab boundaries and responsible practice.

Hardware

Real products students should understand

Raspberry Pi

Raspberry Pi is a small single-board computer used for local labs, home servers, IoT projects, and embedded experiments. Students learn how to host services safely, understand Linux systems, and simulate environments without affecting production systems.

Student question:

Why is Raspberry Pi useful for learning cybersecurity before using a real enterprise environment?

Flipper Zero

Flipper Zero is a multifunction hardware tool often used for RFID, NFC, infrared, and wireless experiments. It is a good example of how hardware can interface with the digital world, which is why students study device protocols, access control systems, and secure design.

Student question:

How do hardware tools help students understand wireless and embedded-device security?

Flipper Zero Modules

The device supports multiple interaction modes such as IR and iButton. This helps students understand how reading, replaying, and analyzing protocol-based interactions work. It also demonstrates why security controls must be properly designed and authenticated.

Student question:

What is the difference between understanding a protocol and exploiting it in a lab environment?

Tools

Core tools students use regularly

nmap

Service discovery and network scanning.

nmap -sC -sV 10.0.2.15

Wireshark

Packet analysis and protocol inspection.

tcpdump -i eth0 -w capture.pcap

Burp Suite

Web app testing and traffic manipulation.

sqlmap

Automated SQL injection testing.

sqlmap -u "http://target/vuln.php?id=1" --batch

Metasploit

Exploit framework for safe lab learning.

LinPEAS

Privilege escalation enumeration.

Hashcat

Password hash analysis and lab practice.

BloodHound

Active Directory path mapping and understanding roles.

Labs

How students practice

Lab 1 — Linux & networking

Install a VM, learn IP addressing, ports, packet captures, process management, and safe environment isolation.

Lab 2 — Web testing

Learn HTTP requests, Burp inspection, OWASP issues, and how to record evidence responsibly.

Lab 3 — Exploitation

Practice the vulnerability lifecycle: enumeration, exploitation, system control, and reporting without harming real systems.

Lab 4 — Privilege escalation

Study sudo misconfigurations, SUID binaries, service permissions, and problem-solving under controlled conditions.

Lab 5 — Hardware & SDR

Understand device communication, radio signals, embedded devices, and controlled hardware experiments.

Lab 6 — Reporting

Create professional findings, evidence summaries, impact analysis, and mitigation steps for a security test.

Legal

Use it safely and responsibly.

  1. Only test systems you own or have explicit written permission to assess.
  2. Keep lab traffic fully isolated from real devices, networks, and production environments.
  3. Do not perform wireless or hardware testing on unauthorized ranges or devices.
  4. Document findings with evidence, risk analysis, and proper remediation guidance.

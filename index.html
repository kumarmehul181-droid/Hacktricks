Curriculum

Roadmap & Units

Level 1 — Foundations (0–3 months)

  • Networking: TCP/IP, ports, DNS, ARP
  • Linux: filesystem, permissions, bash
  • Lab setup: VirtualBox, Kali, isolated networks
  • Basic tools: nmap, tcpdump, Wireshark
  • Deliverable: 2 writeups

Level 2 — Core Skills (3–9 months)

  • Reconnaissance, subdomain enumeration
  • Web testing: OWASP Top 10, Burp Suite
  • Scripting: Python automation
  • Deliverable: 4–6 writeups + mini-project

Level 3 — Professional (9+ months)

  • Privilege escalation and AD fundamentals
  • Post-exploitation and pivoting
  • Reporting: CVSS, remediation, executive summary
  • Deliverable: comprehensive pentest-style report
Hardware

Devices & how to use them (lab-only)

Raspberry Pi

Use: low-cost lab server, host vulnerable apps, VPN jump-hosts, IoT testbeds.

Models: Pi 4 (4GB+), Pi Zero W.

Projects: host DVWA, Juice Shop; run static CTF VM; local DNS server.

Safety: keep on isolated VM networks; never expose to production internet.

Flipper Zero

Use: multi-protocol gadget for IR, RFID, NFC, GPIO experimentation in lab.

Example labs: read/write a lab RFID tag, IR replay for lab devices.

Legal: Sub-GHz transmissions and cloning may be regulated — use only on owned devices.

RTL-SDR & HackRF

RTL-SDR: RX-only inexpensive dongle for passive radio capture (FM, ADS-B).

HackRF One: TX/RX capable — only use with authorization in shielded labs.

Tools: Gqrx, CubicSDR, dump1090 for ADS-B.

Proxmark3 & NFC tools

Low-level RFID research: cloning & analysis in controlled lab with owned tags.

YubiKey & Hardware tokens

Practice MFA, U2F, and hardware-backed authentication flows for secure setups.

USB Rubber Ducky & WiFi Pineapple

Rubber Ducky: HID injection test device (lab-only). WiFi Pineapple: wireless auditing appliance (lab-only).

Budget tip: start with Raspberry Pi + RTL-SDR; add Flipper Zero when comfortable.
Tools

Catalog — what, why, and quick commands

nmap

Network discovery and service detection.

nmap -sC -sV -p- 10.0.2.15

Wireshark / tcpdump

Packet capture and analysis.

tcpdump -i eth0 -w capture.pcap

Burp Suite

Manual web application testing: intercept, repeater, intruder.

sqlmap

Automated SQL injection testing (lab-only).

sqlmap -u "http://10.0.2.15/vuln.php?id=1" --batch

Metasploit

Exploitation framework (use as learning tool).

LinPEAS / WinPEAS

Privilege escalation enumeration scripts.

Note: Always document commands and outputs in writeups. Never run tools outside authorized lab environments.
Labs

Unit plans & sample exercises

Unit 0 — Lab setup

Objectives: Install Kali, create host-only network, snapshot VMs.

Exercise: Deploy DVWA on a target VM, verify attacker can reach it.

Unit 1 — Recon & Networking

Use nmap to discover services and Wireshark to capture HTTP.

Unit 2 — Web testing

Use Burp to find XSS or SQLi vulnerabilities; document reproduction and remediation.

Unit 3 — Exploitation & scripting

Run a public exploit in lab or write a Python automation script for recon.

Unit 4 — Privilege Escalation

Run LinPEAS and enumerate misconfigurations to obtain local privilege escalation.

Unit 5 — Hardware mini-project

Use Raspberry Pi to host a test service; use Flipper Zero to safely interact with a lab-owned tag.

Contribute

Writeups & lesson submissions

Writeup structure

Place writeups under writeups/<level/><machine-name>. Use the template shown in the Labs section. Ensure safety and do not disclose sensitive info.

How to propose changes

Fork, create a branch, add your files, and open a PR. Title example: "Add Level 2 - XSS lab writeup".

Review criteria

Clarity, safety (lab-only), and educational value — explain why the issue exists and how to fix it.

Legal & Safety

Rules you must follow

  1. Use only on machines you own or have explicit written permission to test.
  2. Isolate lab networks from home/work networks (Host-only/NAT).
  3. Do not transmit on radio bands without license; use SDRs passively unless authorized.
  4. Keep logs, evidence, and writeups for every test.

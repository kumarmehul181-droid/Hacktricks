# HACKTRICKS — Ethical Hacking Learning Hub 🛡️

Student-focused cybersecurity learning site (educational purpose only).

**Live:** https://kumarmehul181-droid.github.io/Hacktricks/

## What's inside
- 🧠 **Cybersecurity Awareness Quiz** — a daily question for every visitor + full 8-question quiz (phishing, OTP scams, digital arrest, ransomware — India-relevant)
- 🗺️ **12-week roadmap** — Linux → Recon → Web → Exploitation → Passwords/Wireless → CTF/career
- 🛠️ **Tool catalog** — 14 tools with logos, key commands, official links + comparison table
- 📋 **Cheatsheets** — nmap, burp, linux privesc, windows privesc
- 💻 **Hands-on labs** — Python port scanner, subdomain finder, hardware guide, writeup template
- ⚖️ **Legal section** — IT Act 2000 guidance, complaint links (cybercrime.gov.in, helpline 1930)

## Disclaimer
Content is for education and legal lab practice only (TryHackMe, HackTheBox, DVWA, your own systems). Unauthorized access to systems is a criminal offence under India's IT Act 2000.
